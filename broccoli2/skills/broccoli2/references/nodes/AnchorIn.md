# AnchorIn — вход якоря

Прячет длинную связь: что пришло сюда, то выйдет из одноимённого AnchorOut, а провод через всю
канву рисовать не нужно.

Входы
- Name — имя якоря, текст. По нему и находится пара. По умолчанию «Новый якорь».
- Input — то, что прячем.

Выход
- Output — служебный: им якорь связывается с парным AnchorOut.

Пара соединяется связью AnchorIn.Output -> AnchorOut.Input, и у обеих нод должно стоять одно и
то же имя. Связь между ними рисуется полупрозрачной — логически это один провод.

Не работает внутри селектора: в мире выражений якоря останавливают компиляцию.
