# AnchorIn — вход якоря

Прячет длинную связь: что пришло сюда, то выйдет из одноимённого AnchorOut, а провод через всю
канву рисовать не нужно.

Входы
- Name — имя якоря, текст. По нему и находится пара. По умолчанию «Новый якорь» — переименуй
  сразу, иначе два якоря по умолчанию склеятся.
- Input — то, что прячем.

Выход
- Output — служебный: им якорь связывается с парным AnchorOut.

Пару связывает сам конструктор — скрытой связью AnchorIn.Output -> AnchorOut.Input по
одинаковому имени. Логически это один провод.

Внутри селектора якорь работает так же, как снаружи: он внутри, если несёт значение, зависящее от
объекта селектора, иначе снаружи.

Ограничения
- Вход якоря на имя — один. Скрытая связь, которая замкнула бы цикл, не создаётся: AnchorOut тогда
  останется пустым.
- Имя не должно быть пустым: такой якорь не восстановится при следующем открытии схемы.
