# SpatialJoin — пространственное соединение

Сводит два потока по геометрическому отношению: какие объекты A пересекаются с объектами B,
лежат внутри них или рядом.

Входы
- InputA — первый поток, IFlow<>. Именно он делится на выходы.
- InputB — второй поток, IFlow<>.
- Relation — отношение, перечисление SpatialRelation: Intersects, NotIntersects, Inside,
  Contains, Nearer. По умолчанию Intersects.
- Tolerance — допуск, число. Для Nearer это расстояние.

Выходы
- Matched — объекты A, у которых нашлась пара в B.
- Unmatched — объекты A без пары.
- Pairs — сами пары, потоком групп.

Дорогая нода: геометрию Revit быстрым фильтром не заменить. Отбирай потоки по категории и виду
до неё, а не после.
