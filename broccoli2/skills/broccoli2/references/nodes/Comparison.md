# Comparison — сравнение

Сравнивает два значения и отдаёт да/нет.

Входы
- OperandA — первое значение: текст, число `double` или да/нет. Только связью, ровно одна. Его
  тип задаёт тип всего сравнения.
- Operator — оператор. Набор следует за типом операнда A сам: TextComparison, NumberComparison или
  BooleanComparison.
- OperandB — второе значение: значением или одной связью. Тип и порт подстраиваются под
  операнд A.

Выход
- Result — да/нет. Это поток из одного значения, как у всех скалярных выходов.

Оператор и операнд B задаются после связи операнда A: до неё тип операнда B не выведен, и
значение тул не примет. `scheme_apply` ставит значения ноды после её связей сам, так что числовое
сравнение описывается одной нодой: связь в OperandA, Operator = GreaterThan, OperandB = 200 — без
`definitions`.

Текст сравнивается без учёта регистра, в регулярных выражениях (`IsMatch`, `IsNotMatch`) тоже.

Ограничения
- Пока операнд A не связан, тип не определён: ни оператора, ни операнда B не задать.
- Каждый операнд должен дать ровно одно значение, иначе проверка остановится с ошибкой «должен
  получить ровно одно значение».
- Числа — только `double`: ID элементов (`long`) в OperandA не подать, связь покраснеет.
