# Comparison — сравнение

Сравнивает два значения и отдаёт да/нет.

Входы
- OperandA — первое значение: текст, число или да/нет. Одна связь либо значение.
- Operator — оператор. Набор зависит от определения входа: TextComparison, NumberComparison или
  BooleanComparison.
- OperandB — второе значение, задаётся значением.

Выход
- Result — да/нет. В потоковом мире это поток из одного значения.

Определение переключается scheme_select_definition ключами string, double, bool — вместе с ним
меняется и набор операторов. Оператор из чужого перечисления схема считает ошибкой, а не «нет».

Тип сравниваемых значений берётся из типов операндов, а если оба заданы значениями — из самих
значений. Сравнивая числа, выбирай определение double: как строки «0.5» и «0,50» не равны.
