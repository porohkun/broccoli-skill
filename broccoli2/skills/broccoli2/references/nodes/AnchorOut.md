# AnchorOut — выход якоря

Продолжает связь, начатую одноимённым AnchorIn.

Входы
- Name — имя якоря, текст. Должно совпадать с именем парного AnchorIn.
- Input — служебный: сюда сама приходит скрытая связь от AnchorIn.Output.

Выход
- Output — то, что было подано в парный AnchorIn.

Выходов якоря на одно имя может быть сколько угодно — они получают одно и то же.

Внутри селектора работает так же, как снаружи.

Ограничения
- Без AnchorIn с тем же именем на выходе ничего не будет. Пусто будет и тогда, когда скрытая
  связь замкнула бы цикл: конструктор её не создаёт.
- Если имена разошлись или на одно имя нашлось несколько входов, лишние связи конструктор оборвёт
  сам при открытии схемы.
