# AnchorOut — выход якоря

Продолжает связь, начатую одноимённым AnchorIn.

Входы
- Name — имя якоря, текст. Должно совпадать с именем парного AnchorIn.
- Input — служебный: сюда приходит связь от AnchorIn.Output.

Выход
- Output — то, что было подано в парный AnchorIn.

Если имена разошлись или на одно имя нашлось несколько пар, лишние связи конструктор оборвёт сам
при открытии схемы.

Не работает внутри селектора: в мире выражений якоря останавливают компиляцию.
