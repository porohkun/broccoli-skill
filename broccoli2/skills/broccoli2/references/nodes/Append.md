# Append — присоединить

Присоединяет к потоку элементы из Item: другой поток или одиночные значения.

Чтобы свести ветки схемы, Append не нужен: подключи все потоки прямо к входу-потоку следующей
ноды. Вход-поток, у которого связей сколько угодно, объединяет пришедшие потоки сам.

Входы
- Input — поток, IFlow<>, связей сколько угодно.
- Item — одиночные значения или поток, принимает что угодно. Без связи нода ничего не
  присоединяет и пропускает Input как есть; анализатор предупреждает об этом в scheme_check.

Выход
- Result — общий поток. Тип — общий для всего, что пришло: если слить поток типов элементов с
  потоком элементов, получится поток элементов.

Если общий тип не находится, все связи кроме первой краснеют. Смотри scheme_inspect: там видно,
какой тип стал опорным.
