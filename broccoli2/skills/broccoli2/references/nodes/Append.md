# Append — присоединить

Добавляет в поток другой поток или одиночные значения. Так сводят вместе ветки схемы.

Входы
- Input — поток, IFlow<>, связей сколько угодно.
- Item — одиночные значения или поток, принимает что угодно.

Выход
- Result — общий поток. Тип — общий для всего, что пришло: если слить поток типов элементов с
  потоком элементов, получится поток элементов.

Если общий тип не находится, все связи кроме первой краснеют. Смотри scheme_inspect: там видно,
какой тип стал опорным.
