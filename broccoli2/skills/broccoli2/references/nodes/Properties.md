# Properties — свойства объекта

Раскрывает свойства пришедшего объекта отдельными выходами. Главный переход схемы: из документов
в элементы.

Входы
- Object — объект или поток объектов, принимает что угодно.
- Distinct — галочка, убирать ли повторы. По умолчанию да.

Выходы
- Состав зависит от типа входа и появляется только после того, как вход подключён. У документа
  это Elements, Parameters, Title, ModelPath, PathName, IsLink; у элемента — свои свойства.
- Тип выхода потоковый, если вход потоковый: документов много — значит, и элементов много.

Спроси scheme_describe после подключения входа: до этого выходов у ноды просто нет, и связать
их не с чем.
