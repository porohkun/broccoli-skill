# CustomSelectorBase — база селектора

Начало визуального селектора: отдаёт тот самый объект, к которому будет применяться условие.

Вход
- InputType — тип объекта. Проставляется потребителем через CustomSelector, руками не задаётся.

Выходы
- Base — служебная связь с CustomSelector, ровно одна. Ею конструктор понимает, где кончается
  подграф условия.
- Element — сам объект. От него и строят вычисление.

Сам по себе смысла не имеет: работает только в паре с CustomSelector.
