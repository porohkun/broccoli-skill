# CustomSelectorBase — база селектора

Начало тела селектора: отдаёт тот объект, на котором вызвана функция.

Вход
- InputType — тип объекта. Проставляется потребителем через CustomSelector, руками не задаётся.

Выходы
- Base — служебная связь с CustomSelector.Base, ровно одна. Ею конструктор понимает, чьё это
  тело.
- Element — сам объект: элемент, группа, параметр — что проверяется. Один объект, не поток; потоки
  внутри получаются из него — элементы документа через `Properties`, объекты группы — прямо из
  группы.

Тип объекта приходит справа: потребитель пишет его в CustomSelector, тот — в базу. Пока селектор
не связан с потребителем, Element — Object.

Ограничения
- Работает только в паре с CustomSelector. Element читают, а Base никуда не подключён — ошибка
  сборки схемы.
