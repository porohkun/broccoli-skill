# Model — основная модель

Источник документов: сама модель и её связи Revit. С неё начинается почти любая схема.

Входы
- MainModel — галочка, включать ли основную модель. По умолчанию да.
- Links — галочка, включать ли связанные модели. По умолчанию да.
- Disciplines — текст, оставить связи только этих дисциплин; несколько — через «|». Пусто — все.
- Parts — текст, то же для частей (разделов). Пусто — все.

Выход
- Result — документы. Тип зависит от галочек: только основная модель без связей даёт одиночный
  IDocument, во всех остальных случаях — поток IFlow<IDocument>.

Дальше от документов идут к элементам через `Properties`: у документа есть выход Elements.

Дисциплина и часть берутся из имени файла связи, разбитого по «-»: пятое поле — дисциплина,
шестое — часть. В ПРО-П-01-К1-АР-О дисциплина АР, часть О. Совпадение — по вхождению: «АР»
подойдёт и к «АР1». Файл, названный не по правилам, под фильтр не попадёт; библиотечные файлы
(lib) не попадают никогда.

Связь, вставленная в модель в несколько мест, по умолчанию даёт схеме один документ; документ на
каждое место — настройка схемы DocumentPerLinkInstance. Связи самой связи в схему не попадают.
Как это отражается на габаритах — geometry.md.

Внутри селектора нода считается один раз, а не на каждом объекте: от объекта она не зависит.

Не умеет: выбирать документ по имени. Отбор связей — только по дисциплине и частям имени.
