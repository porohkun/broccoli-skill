# GroupBy — сгруппировать

Собирает объекты потока в группы по ключу, который даёт селектор, и отдаёт поток групп.

Входы
- Input — поток, IFlow<>.
- Selector — ключ группы, ровно одна связь: селектор, который на объект даёт одно значение — текст,
  число, ID. Например, `CustomSelector` с `Properties.OwnerViewId` — группы по листам.

Выход
- Result — поток групп, IFlow<IGroup<элемент, ключ>>: сначала тип объекта, потом тип ключа.
  Группы появляются, когда собран весь вход.

Группа — поток своих объектов. Её читают так же, как поток: селектор над группой (`Where`,
`SelectMany`) получает в Element группу, и её объекты идут прямо в `Where`, `Length`, `Sum` и
другие потоковые ноды тела. `Where`, `SplitBy`, `TernaryCondition`, `Append`, получив группу на
вход, отдают поток её объектов.

`SaveError` групп не принимает: объекты групп возвращает в общий поток `SelectMany`.

Это не то же, что SplitBy: SplitBy разводит поток по заранее известным выходам, GroupBy отдаёт
один выход с группами, сколько бы ключей ни нашлось.

Ограничения
- Текстовые ключи сравниваются без учёта регистра: «ОСТ-1» и «ост-1» — одна группа.
- Селектор, который на объект даёт поток, схема не примет при сборке: ключ — одно значение.
- Без селектора проверка остановится с ошибкой «Селектор не имеет значения».
