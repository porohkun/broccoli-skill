# GroupBy — сгруппировать

Делит поток на группы по ключу, который даёт селектор, и отдаёт поток групп.

Входы
- Input — поток, IFlow<>.
- Selector — ключ группы, ровно одна связь. Результат селектора — что угодно: строка, число.

Выход
- Result — поток групп, IGroup<ключ, элемент>. Это не плоский поток: потребитель должен уметь
  читать именно группы.

Это не то же, что SplitBy. SplitBy разводит поток по нескольким выходам и каждую часть отдаёт
плоским потоком; GroupBy отдаёт один выход с группами.
