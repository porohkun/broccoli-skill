# SaveError — сохранить как ошибку

Записывает элементы в результат инспекции ошибкой. Ими проверка и заканчивается: без стока поток
посчитается и пропадёт.

Входы
- Input — поток элементов, IFlow<IElement>. Именно элементов: документы, параметры, числа и группы
  сюда не подключить. Группы сначала разворачивает `SelectMany`.
- Text — текст ошибки, который прочитает человек в отчёте. Задаётся значением или приходит
  строкой по одной связи. Обязателен: без текста схема не компилируется — здоровье схемы покажет
  это ошибкой на ноде, а пустая строка, пришедшая по связи, остановит инспекцию при исполнении.

Выходов нет.

Текст пиши о том, что не так с элементом, а не о том, что сделала схема: «Стена без типа», а не
«Отфильтровано по параметру».

Ограничения
- Только в основной схеме: внутри селектора — ошибка сборки, наружу значение выходит через
  `CustomSelector`.
- Элемент, пришедший дважды, попадёт в отчёт дважды.
