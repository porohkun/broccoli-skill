# OfType — отобрать по виду элемента

Оставляет объекты выбранного вида и уточняет тип потока: после него дальше идёт не «что угодно»,
а именно тот вид, который выбран.

Входы
- Input — поток, IFlow<>.
- Kind — вид элемента, перечисление ElementKind: Element или ElementType. По умолчанию ElementType.

Выходы
- Result — объекты выбранного вида, тип потока уточнён.
- Rest — всё остальное, тип совпадает с входом. Строится только если подключён.

Умеет быстрый фильтр: отбор по виду Revit делает сам, элементы других видов не материализуются.
Ставь его рядом с источником, а не после дорогих вычислений.

Не умеет: расширять поток обратно. Если поток уже уточнён до типов элементов, отбор по более
общему виду его не расширит.
