# CategoryFilter — фильтр по категориям

Отдаёт селектор «элемент нужной категории». Самый дешёвый отбор в конструкторе вместе с
`ElementKindFilter`: сворачивается в быстрый фильтр Revit, и элементы других категорий не
материализуются вовсе.

Входы
- Category — категории системными именами Revit: OST_Walls, OST_Doors. Несколько — через «|».
- Include — галочка. Да: оставить перечисленные. Нет: оставить всё, кроме них. По умолчанию да.

Выход
- Result — ISelector<IElement, Boolean>.

Ставь его как можно ближе к источнику: чем раньше в цепочке, тем больше отдаст Revit сам. Вид
элемента он не уточняет — для этого `ElementKindFilter`, и порядок двух отборов неважен: в запрос
к модели уйдут оба.

Ограничения
- Категория — системное имя `OST_Walls`, а не «Стены»; такое же отдаёт выход Category у
  `Properties`.
- Без категорий проверка остановится с ошибкой «Не указана категория».
- Категории можно подать связью-потоком, но тогда нода отдаст поток селекторов, а `Where` такую
  схему не выполнит. Перечисляй через «|» в самом фильтре.
- Внутри селектора категория вписывается значением, а не приходит связью, иначе проверка
  остановится с ошибкой.
