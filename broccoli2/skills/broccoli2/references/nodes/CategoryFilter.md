# CategoryFilter — фильтр по категориям

Отдаёт селектор «элемент нужной категории». Самый дешёвый отбор в конструкторе: он один
сворачивается в быстрый фильтр Revit, и элементы других категорий не материализуются вовсе.

Входы
- Category — категории системными именами Revit: OST_Walls, OST_Doors. Несколько — через «|».
- Include — галочка. Да: оставить перечисленные. Нет: оставить всё, кроме них. По умолчанию да.

Выход
- Result — ISelector<IElement, Boolean>.

Категории можно подать и связью-потоком, но тогда нода отдаст поток селекторов, а Where такую
схему не выполнит. Перечисляй через «|» в самом фильтре.

Ставь его как можно ближе к источнику: чем раньше в цепочке, тем больше отдаст Revit сам.
