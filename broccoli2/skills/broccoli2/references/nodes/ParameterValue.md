# ParameterValue — значение параметра

Читает параметр одного элемента.

Входы
- Element — элемент, ровно одна связь.
- ParameterName — имя параметра, текст.
- ParameterType — каким типом читать: перечисление ValueType — String, Double, Bool.
  По умолчанию String.

Выход
- Result — значение. Тип — тот, что выбран в ParameterType.

Читает у одного элемента, а не у потока. Чтобы отобрать поток по параметру, бери ParameterFilter:
он и дешевле, и местами сворачивается в быстрый фильтр.

Параметры «да/нет» Revit хранит числом — выбирай Bool, приведение конструктор сделает сам.
