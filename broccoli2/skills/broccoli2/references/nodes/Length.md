# Length — длина потока

Сколько объектов прошло по потоку.

Вход
- Input — поток, IFlow<>. Группа тоже годится: внутри селектора над группой так считают её
  объекты.

Выход
- Result — число. Это поток из одного значения: так устроены все скалярные выходы конструктора.

Считает то, что дошло до неё: ставить её надо после отборов, а не до. Число получается, когда
посчитан весь поток.

Внутри селектора — обычная нода: «в группе больше одного элемента» — это `Length` над группой и
`Comparison` с оператором GreaterThan и числом 1 в теле селектора `Where` по группам.
