# ParameterFilter — фильтр по параметрам

Отдаёт селектор «параметр элемента сравнился со значением».

Входы
- Parameter — имя параметра, текст, одна связь либо значение.
- Operator — оператор. Набор зависит от определения: текст, число или да/нет.
- Value — с чем сравнивать. Тип и редактор тоже от определения: текст, число или галочка.

Выход
- Result — ISelector<IElement, Boolean>.

Определение переключается у входа Value — `scheme_select_definition` ключами string, double,
bool, — и Operator следует за ним сам; переключать Operator отдельно бесполезно. Тип параметра
фильтр сам не узнаёт. Число сравнивай в числовом определении: как текст «0.5» и «0,50» разные.

Текстовое значение понимает перечень и звёздочки. `Ст-1 | Ст-2` — совпало с любым из значений,
пробелы по краям не учитываются, пустое значение учитывается: `Ст-1|` — это «Ст-1 или пусто».
`Ст-*` — начинается с, `*-1` — заканчивается на, `*Ст*` — содержит, одна `*` — что угодно;
звёздочка внутри значения — обычный символ. Регистр не учитывается: `Ст-1` и `ст-1` — одно
значение. С `≠` всё читается наоборот: не совпало ни с одним. В регулярках (`IsMatch`,
`IsNotMatch`) `|` и `*` — символы самой регулярки, регистр не учитывается и там.

Параметры «да/нет» Revit хранит целым числом, конструктор приводит это сам — сравнивай с
true/false, а не с 1.

Быстрый фильтр умеет не всегда: где Revit спросить параметр не может, отбор считается на элементах.
Отбор по категории и виду ставь раньше.

Ограничения
- Элемент без такого параметра не проходит фильтр никогда, даже с `≠`.
- Без имени параметра проверка остановится с ошибкой «Не указано имя параметра».
- Внутри селектора имя параметра вписывается значением, а не приходит связью.
