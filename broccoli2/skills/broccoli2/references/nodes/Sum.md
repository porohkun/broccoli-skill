# Sum — суммировать

Складывает числа, которые селектор даёт на каждом объекте потока.

Входы
- Input — поток, IFlow<>.
- Selector — чем брать число с объекта, ровно одна связь. Желаемый тип результата — число.
  Селектор-функция (`CustomSelector`) обязана дать на объект ровно одно число.

Выход
- Result — сумма. Это поток из одного значения.

Порядок: Input раньше Selector, иначе селектор не узнает тип объектов. `scheme_apply` соблюдает это
сам.

Считать количество не нужно — для этого есть Length.

Ограничения
- Селектор обязателен: без него проверка остановится с ошибкой «Селектор не имеет значения».
- Селектор с ответом не числом (например, да/нет) — красная связь; с ответом не того типа из
  выражения — остановка схемы при сборке.
- Быстрым не бывает: элементы для суммы всегда вычитываются из модели.
