# Dictionary — словарь

Таблица «ключ — значение»: например, сопоставление категории и допустимого значения параметра.

Вход
- Data — сама таблица. Вид выбирается определением: string — словарь строк, double — словарь чисел.
  Задаётся значением целиком, отдельными строками не правится.

Выход
- Result — словарь.

Определение переключается scheme_select_definition ключами string и double. Словаря «да/нет» нет:
такой тип в конструкторе никто не производит.
