# CustomSelector — селектор из нод

Условие, собранное нодами, а не написанное кодом. Всё, что подключено к нему назад, компилируется
в выражение и применяется к каждому объекту по отдельности.

Входы
- InputType — тип объекта, к которому применяется условие. Проставляется потребителем, руками
  не задаётся.
- ResultType — тип ответа. Тоже от потребителя.
- Base — связь с нодой CustomSelectorBase, ровно одна.
- Output — что считать ответом условия, ровно одна связь.

Выход
- Result — селектор.

Собирается так: CustomSelectorBase даёт элемент, дальше любые вычисления над ним, результат
приходит в Output.

Внутри действуют ограничения мира выражений: якоря не работают, категория и имя параметра должны
быть известны значением. Разбор — expression-world.md.
