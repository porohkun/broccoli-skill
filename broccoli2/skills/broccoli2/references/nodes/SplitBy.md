# SplitBy — разделить на

Разводит поток по нескольким выходам: значение селектора решает, в какой выход попадёт объект.

Входы
- Input — поток, IFlow<>.
- Selector — чем делить, ровно одна связь.

Выходы
- Состав появляется от селектора: выходы называются значениями, которые селектор объявил. До
  подключения селектора выходов нет.

Каждый выход — плоский поток тех же объектов. Если нужны именно группы, а не ветки схемы, бери
GroupBy.
