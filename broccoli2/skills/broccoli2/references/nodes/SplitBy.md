# SplitBy — разделить на

Разводит поток по нескольким выходам: значение селектора решает, в какой выход попадёт объект.

Входы
- Input — поток, IFlow<>. Группа на входе читается как поток её объектов.
- Selector — чем делить, ровно одна связь. Селектор обязан заранее знать варианты ответа:
  годятся `CategoryFilter`, `ElementKindFilter` и `ParameterFilter`. `CustomSelector`,
  `ExpressionSelector` и `CombineFilter` вариантов не сообщают — связь покраснеет.

Выходы
- Состав появляется от селектора: выходы называются значениями, которые селектор объявил. До
  подключения селектора выходов нет.

Каждый выход — плоский поток тех же объектов; на входе-группе — поток её объектов. Если нужны
именно группы по значениям, которые заранее неизвестны, бери GroupBy.

Ограничения
- Без селектора проверка остановится с ошибкой «Селектор не имеет значения».
- Выход, который пропал после смены селектора, остаётся фантомом со связями, и схема не
  компилируется, пока их не оборвать.
