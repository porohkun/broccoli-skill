# BoundingBoxComparison — сравнение габаритов

Проверяет отношение двух габаритов и отдаёт да/нет.

Входы
- OperandA — габариты A, ровно один BoundingBox, одна связь.
- Relation — отношение, перечисление BoundingBoxRelation. По умолчанию Intersects.
  - Intersects — у габаритов есть общая часть; касание гранью тоже пересечение.
  - Contains — A целиком охватывает B.
  - Inside — A целиком лежит в B.
- OperandB — габариты B, ровно один BoundingBox, одна связь.

Выход
- Result — да/нет. Как у `Comparison`, это поток из одного значения.

Ставится внутри селектора: «текст наложен на спецификацию» — это селектор над текстом, в котором
его габарит сравнивается с габаритами спецификаций. Разбор такой проверки — geometry.md.

Ограничения
- Допуска нет: допустимое наложение задают сжатием в `BoundingBoxTransform`.
- Пустые габариты ничего не пересекают и ничего не содержат: ответ с ними — «нет».
- В каждый операнд должен прийти ровно один габарит, иначе схема остановится с ошибкой.
