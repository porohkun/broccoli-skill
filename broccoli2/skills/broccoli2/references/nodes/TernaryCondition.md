# TernaryCondition — условие

Пускает поток в один из двух выходов в зависимости от условия. Условие проверяется один раз на
весь поток, а не на каждый объект: для «каждого по отдельности» есть Where.

Входы
- Input — поток, IFlow<>. Группа на входе читается как поток её объектов.
- Condition — да/нет, ровно одна связь. В редакторе задаётся только связью: значение, которое
  поставил бы тул, человек в редакторе не увидит. Связь должна дать ровно одно значение.

Выходы
- ResultOnTrue — поток, если условие истинно.
- ResultOnFalse — поток, если ложно.

На входе-группе выходы — поток её объектов. Оба выхода строятся независимо: подключишь оба —
источник в плане запроса продублируется.

Ограничения
- Поток из нескольких значений в Condition останавливает проверку: «должен получить ровно одно
  значение».
- Без Input проверка остановится с ошибкой «Вход 'Поток' не подключен».
