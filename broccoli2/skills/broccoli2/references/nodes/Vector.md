# Vector — вектор

Собирает вектор из трёх координат в миллиметрах: направление или смещение для нод геометрии.

Входы
- X, Y, Z — координаты, мм, число. По умолчанию 0. Каждая — значением или одной связью, по
  которой придёт ровно одно число.

Выход
- Result — Vector3, ровно одно значение.

Потребитель — `BoundingBoxTransform`: его вектор приходит только связью от этой ноды. Нормаль
горизонтальной плоскости — (0, 0, 1): Z = 1, X и Y по нулям.

Ограничения
- Поток из нескольких чисел в координате останавливает схему ошибкой с именем координаты.
