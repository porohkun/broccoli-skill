# ResultPercentBase — база для процента результата

Задаёт знаменатель, когда результат нужен в процентах: сколько элементов вообще проверялось.

Вход
- Input — поток элементов, IFlow<IElement>. Это те, что считаются проверенными.

Выходов нет.

Без неё «12 ошибок» остаётся числом; с ней превращается в «12 из 400». Подключай к ней поток до
отборов, которые ищут нарушения, — иначе знаменатель совпадёт с числителем.
