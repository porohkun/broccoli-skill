# BoundingBoxTransform — преобразование габаритов

Сдвигает, проецирует на плоскость, расширяет или сжимает габариты на вектор.

Входы
- Input — один BoundingBox или поток IFlow<BoundingBox>, одна связь: например, выход BoundingBox
  у `Properties` над элементом.
- Operation — операция, перечисление BoundingBoxOperation. По умолчанию Move.
  - Move — сдвинуть на вектор.
  - Project — спроецировать на координатную плоскость; вектор — её нормаль, строго вдоль оси.
    (0, 0, 1) — проекция на план.
  - Expand — расширить во все стороны на величины вектора по осям.
  - Contract — сжать со всех сторон. Ось нулевой толщины не сжимается; сжатый сильнее своего
    размера габарит становится пустым.
- Vector — величины по осям, мм, ровно одно значение. Только связью от `Vector`: текстом этот
  вход не задаётся.

Выход
- Result — преобразованные габариты той же формы, что вход: один габарит или поток.

Две главные задачи: сравнить положение на плане без высоты (Project с нормалью (0, 0, 1)) и
задать допустимое наложение — `BoundingBoxComparison` допуска не знает, поэтому габарит заранее
сжимают на допуск (Contract).

Ограничения
- Без вектора схема не компилируется.
- Нормаль проекции не вдоль оси останавливает схему ошибкой.
- Пустые габариты остаются пустыми при любой операции.
