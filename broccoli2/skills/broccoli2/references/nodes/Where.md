# Where — выбрать часть потока

Оставляет в потоке объекты, на которых селектор ответил «да».

Входы
- Input — поток, IFlow<>, связей сколько угодно: объекты из всех идут дальше одним потоком.
  Группа тоже годится: тогда отбираются её объекты.
- Selector — условие, ровно одна связь. Желаемый тип подстраивается под поток: на
  IFlow<IElementType> нужен ISelector<IElementType, Boolean>. Селектор по более общему элементу
  подходит — ISelector<IElement, Boolean> ляжет на поток типов.

Выход
- Result — тот же поток без отсеянного. Тип совпадает с Input, кроме двух случаев:
  - селектор задаёт вид — `ElementKindFilter` с Include или `CombineFilter`, в котором вид
    сходится, — тогда поток уточнён до этого вида, и `Properties` за ним даёт свойства вида;
  - на входе группа — тогда на выходе поток её объектов.

Порядок: Input связывай раньше Selector, иначе желаемый тип селектора ещё неизвестен. `scheme_apply`
соблюдает это сам.

Ограничения
- Селектор должен ответить «да»/«нет» ровно одним значением на объект. Селектор-функция
  (`CustomSelector`), которая на объект дала поток или несколько значений, останавливает проверку
  при исполнении; селектор с ответом не того типа останавливает схему при сборке.
- Без селектора проверка остановится с ошибкой «Селектор не имеет значения».
- Условие не приходит потоком: `CategoryFilter`, получивший категории связью-потоком, отдаёт поток
  условий, и `Where` такую схему не выполнит.
