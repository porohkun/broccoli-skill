# SelectMany — развернуть

Сливает потоки в один. Без селектора разворачивает группы: на выходе объекты всех групп подряд. С
селектором берёт для каждого объекта поток, который вернул селектор, и сливает их.

Входы
- Input — поток, IFlow<>. Без селектора — поток групп: выход `GroupBy` или его отбор `Where`.
- Selector — необязательный, ровно одна связь. Селектор-функция, которая на объект отдаёт поток:
  `CustomSelector`, у которого в Output приходит поток, например отбор `Where` из группы.
  Желаемый тип результата — IFlow<Object>.

Выход
- Result — объекты всех потоков подряд, в порядке входа. Тип — тип объектов этих потоков.

Типичная цепочка — «группы, в которых что-то не так, — обратно в элементы»: `GroupBy` → `Where`
по группам → `SelectMany` → `SaveError`. `SaveError` групп не принимает, поэтому `SelectMany` здесь
обязателен.

Ограничения
- Без селектора объекты входа должны быть потоками. Поток элементов развернуть нечем — схема
  остановится с ошибкой.
- `ExpressionSelector` сюда не годится: коллекцию объектов модели выражение не вернёт.
- Повторы не убираются: объект из двух потоков попадёт в результат дважды.
