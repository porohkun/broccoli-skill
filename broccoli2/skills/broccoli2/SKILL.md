# Broccoli2: сборка инспекций

Инспекция — изолированная проверка чертежа на одно ограниченное требование: «у стены заполнен
параметр», «отметка уровня совпадает с именем». Broccoli2 — конструктор таких проверок: схема из
нод и связей, из которой компилируется запрос к модели.

Схему собирают в веб-редакторе мышью либо здесь — тулами MCP. Результат один и тот же: схема,
которая открывается в редакторе и исполняется плагином на модели.

## Что нужно знать раньше всего

**Типы портов не задаёшь ты.** Их выводит резолвер из желаемых типов, которые объявляют сами ноды,
и из типов связей. Ты соединяешь порты, а что получилось — читаешь в ответе тула.

**Несводимая связь не отвергается, а краснеет.** Тул её создаст и скажет «связь некорректна».
Схема с хотя бы одной такой связью **не компилируется целиком** — не «эта ветка не сработает», а
вся инспекция. Поэтому здоровье схемы в ответе каждого тула важнее подтверждения.

**Состав портов у некоторых нод зависит от того, что подключено.** У `Properties` выходы вообще
рождаются от типа входа. Спрашивай `nodes_describe`, а после правок — `scheme_describe`.

**Порядок связывания значим.** Поток подключай раньше селектора: пока нода не знает тип потока,
она не знает и желаемый тип селектора, и связь ляжет под неуточнённый тип.

## Порядок работы

1. `nodes_find` — найти ноды по смыслу, если состав неизвестен.
2. `nodes_describe` — прочитать про ноду: порты, ограничения, чего она не умеет.
3. `scheme_new` или `scheme_open` — завести схему или открыть существующую.
4. `scheme_apply` — собрать схему целиком описанием. Это основной путь.
5. `scheme_check` — убедиться, что некорректных связей нет и схему можно отправлять.
6. `scheme_save` — записать в файл.

Точечные правки делаются `scheme_add_node`, `scheme_link`, `scheme_unlink`, `scheme_set_value`,
`scheme_select_definition`, `scheme_remove_node`. Ими же чинят чужую схему.

Когда связь не сошлась — `scheme_inspect`. Он покажет у портов итоговый тип, желаемый и допустимые:
из них и складывается ответ, почему связь красная. Подробнее — `references/mcp.md` и
`references/troubleshooting.md`.

## Ноды

Полное описание каждой — в `references/nodes/<Тип>.md`. Таблица для выбора:

| Тип | Что делает |
|---|---|
| [Model](references/nodes/Model.md) | Источник документов: основная модель и её связи. С неё начинается почти любая схема |
| [Properties](references/nodes/Properties.md) | Раскрывает свойства объекта отдельными выходами. Из документов так достают элементы |
| [OfType](references/nodes/OfType.md) | Оставляет объекты выбранного вида и уточняет тип потока. Второй выход — всё остальное |
| [Where](references/nodes/Where.md) | Оставляет в потоке объекты, на которых селектор ответил «да» |
| [Append](references/nodes/Append.md) | Добавляет в поток другой поток или одиночные значения |
| [SpatialJoin](references/nodes/SpatialJoin.md) | Сводит два потока по геометрическому отношению: пересекает, внутри, ближе чем |
| [SplitBy](references/nodes/SplitBy.md) | Разводит поток по нескольким выходам, названным значениями селектора |
| [GroupBy](references/nodes/GroupBy.md) | Делит поток на группы по ключу селектора и отдаёт поток групп |
| [TernaryCondition](references/nodes/TernaryCondition.md) | Пускает поток в один из двух выходов по условию |
| [Length](references/nodes/Length.md) | Сколько объектов прошло по потоку |
| [Sum](references/nodes/Sum.md) | Складывает числа, которые даёт селектор на каждом объекте |
| [Comparison](references/nodes/Comparison.md) | Сравнивает два значения и отдаёт да/нет |
| [CategoryFilter](references/nodes/CategoryFilter.md) | Селектор по категориям Revit. Единственный, который сворачивается в быстрый фильтр |
| [ParameterFilter](references/nodes/ParameterFilter.md) | Селектор по значению параметра |
| [CombineFilter](references/nodes/CombineFilter.md) | Склеивает несколько селекторов в один через И или ИЛИ |
| [CustomSelector](references/nodes/CustomSelector.md) | Селектор, собранный нодами, а не кодом |
| [CustomSelectorBase](references/nodes/CustomSelectorBase.md) | Начало такого селектора: отдаёт элемент, к которому применяется условие |
| [ExpressionSelector](references/nodes/ExpressionSelector.md) | Селектор выражением на C# |
| [ParameterValue](references/nodes/ParameterValue.md) | Читает параметр одного элемента |
| [Dictionary](references/nodes/Dictionary.md) | Таблица «ключ — значение» строк или чисел |
| [SaveError](references/nodes/SaveError.md) | Записывает элементы в результат инспекции ошибкой. Ими проверка и заканчивается |
| [SaveMessage](references/nodes/SaveMessage.md) | То же, но сообщением: не ошибка, а замечание |
| [ResultPercentBase](references/nodes/ResultPercentBase.md) | Задаёт знаменатель для процента результата |
| [AnchorIn](references/nodes/AnchorIn.md) | Вход якоря: прячет длинную связь, отдавая её парному выходу по имени |
| [AnchorOut](references/nodes/AnchorOut.md) | Выход якоря: продолжает связь, начатую одноимённым входом |
| [Comment](references/nodes/Comment.md) | Заметка на канве. В инспекции не участвует |
| [Panel](references/nodes/Panel.md) | Рамка на канве. В инспекции не участвует |
